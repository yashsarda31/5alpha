# AlphaNova4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a separate, mobile-first AlphaNova4 frontend whose four core research destinations operate inside one adaptive Three.js universe with GSAP-directed transitions.

**Architecture:** A new `alphanova4` React/Vite/TypeScript package consumes the existing Alpha Nova API through strict normalizers. React owns application state, authentication, semantic controls, and error handling; a persistent Three.js runtime owns the spatial universe; GSAP coordinates interruptible route transitions. The existing `web` frontend and backend remain unchanged.

**Tech Stack:** React 19, React Router 7, TypeScript 5, Vite 8, Three.js 0.166.1, GSAP 3.12.5, Vitest, Testing Library, Playwright, axe-core, ESLint.

## Global Constraints

- Develop in the new top-level `alphanova4` package; do not modify or overwrite `web`.
- Initial routes are exactly `/dashboard`, `/signals`, `/chart`, `/watchlist`, and `/login`.
- Reuse the existing Alpha Nova API, token keys, authentication, watchlist, alert, signal-integrity, provider-limitation, and compliance contracts.
- Base colors are deep midnight/navy, electric blue, and white; gain/loss colors are semantic only and always paired with labels or symbols.
- Use procedural geometry and lightweight generated textures; do not add large 3D models, decorative video, gold accents, broker execution, or new financial claims.
- Essential controls are at least 44 by 44 CSS pixels.
- Invalid numbers never become geometry, displayed prices, confidence values, targets, stops, or risk levels.
- `prefers-reduced-motion`, low-power rendering, WebGL failure, and context loss must retain a usable Essential experience.
- Target 55 to 60 FPS on capable phones and a stable 30 FPS minimum after automatic downgrade.
- Deployment is excluded until the user explicitly approves the verified preview and asks for production replacement.
- Run every repository command through `rtk`.

```ts
export class ApiError extends Error {
  constructor(message: string, public readonly status: number, public readonly body: unknown) {
    super(message);
    this.name = 'ApiError';
  }
}

export async function apiRequest<T>(path: string, init: RequestInit = {}): Promise<T> {
  const token = localStorage.getItem('alphanova_auth_token');
  const response = await fetch(path, {
    ...init,
    headers: {
      ...(init.body ? { 'Content-Type': 'application/json' } : {}),
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
      ...init.headers,
    },
  });
  const text = response.status === 204 ? '' : await response.text();
  let body: unknown = null;
  if (text) {
    try { body = JSON.parse(text); } catch { body = text; }
  }
  const detail = body && typeof body === 'object' && 'detail' in body ? String(body.detail) : null;
  if (!response.ok) throw new ApiError(detail ?? `Request failed: ${response.status}`, response.status, body);
  return body as T;
}
```

- [ ] **Step 3: Implement GSAP route travel with valid settle states**

`SceneDirector.go()` kills the prior timeline, reads the destination zone camera pose, and either animates position/target or applies them immediately for Essential tier. Its completion and interruption callbacks set a valid active route and restore semantic focus.

```ts
go(route: CoreRoute, immediate = false) {
  const transitionId = ++this.transitionId;
  this.active?.kill();
  const pose = this.poses.get(route);
  if (!pose) throw new Error(`Unknown route: ${route}`);
  const settle = () => {
    if (transitionId !== this.transitionId) return;
    this.route = route;
    this.onSettled(route);
  };
  if (immediate || this.transitionScale === 0) {
    this.camera.position.copy(pose.position);
    this.target.copy(pose.target);
    settle();
    return;
  }
  this.active = this.timelineFactory({ onComplete: settle, onInterrupt: settle })
    .to(this.camera.position, { x: pose.position.x, y: pose.position.y, z: pose.position.z, duration: 0.9 * this.transitionScale }, 0)
    .to(this.target, { x: pose.target.x, y: pose.target.y, z: pose.target.z, duration: 0.9 * this.transitionScale }, 0);
}
```

export function createPolyline(points: THREE.Vector3[], color: THREE.ColorRepresentation) {
  const geometry = new THREE.BufferGeometry().setFromPoints(points);
  const material = new THREE.LineBasicMaterial({ color, transparent: true, opacity: 0.92 });

}

export function disposeObject3D(root: THREE.Object3D) {
  root.traverse((node) => {
    const mesh = node as THREE.Mesh;
    mesh.geometry?.dispose();
    const materials = Array.isArray(mesh.material) ? mesh.material : [mesh.material];
    materials.filter(Boolean).forEach((material) => material.dispose());
  });
}

- [ ] **Step 2: Implement cancellable stale-while-refresh loading**

`useResource(key, loader, refreshMs)` keeps the last valid view model, aborts obsolete requests, refreshes dashboard data every 120 seconds while visible, and returns `loading`, `ready`, `stale`, or `error` without clearing valid cached data on a transient failure.

```ts
export function useResource<T>(key: string, loader: (signal: AbortSignal) => Promise<T>, refreshMs: number) {
  const [state, setState] = useState<ResourceState<T>>({ status: 'loading', data: null, error: null });
  useEffect(() => {
    const controller = new AbortController();
    const load = async () => {
      try {
        const data = await loader(controller.signal);
        setState({ status: 'ready', data, error: null });
      } catch (error) {
        if (controller.signal.aborted) return;
        setState((current) => current.data
          ? { status: 'stale', data: current.data, error: null }
          : { status: 'error', data: null, error: error instanceof Error ? error.message : 'Unavailable' });
      }
    };
    void load();
    const interval = refreshMs > 0 ? window.setInterval(() => { if (!document.hidden) void load(); }, refreshMs) : 0;
    return () => { controller.abort(); if (interval) window.clearInterval(interval); };
  }, [key, loader, refreshMs]);
  return state;
}
```

export async function ensureSubscribed(): Promise<PushStatus> {
  if (!('serviceWorker' in navigator) || !('PushManager' in window)) return 'unsupported';
  if (Notification.permission !== 'granted') return 'denied';
  const registration = await navigator.serviceWorker.ready.catch(() => null);

const frameStats = await page.evaluate(async () => {
  const deltas: number[] = [];
  let previous = performance.now();
  while (deltas.length < 180) await new Promise<void>((resolve) => requestAnimationFrame((now) => { deltas.push(now - previous); previous = now; resolve(); }));
  return { average: deltas.reduce((sum, value) => sum + value, 0) / deltas.length, worst: Math.max(...deltas) };
});
